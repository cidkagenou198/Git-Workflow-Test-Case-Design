================================================================================
GIT COMMANDS DOCUMENTATION - ASSIGNMENT WORKFLOW
================================================================================

1. git init -b main
Initializes a new, empty Git repository in the current project directory and sets the default initial branch to 'main'.

2. git status
Displays the state of the working directory and staging area, showing which files are untracked, modified, or staged for commit.

3. git add index.html about.html
Stages the specified files (index.html and about.html), adding their current state to the index in preparation for the initial commit.

4. git commit -m "Initial commit: Add index.html and about.html"
Creates a new commit containing the staged files along with a descriptive commit message recording the initial project snapshot.

5. git add index.html
Stages the modified index.html file after adding the project features section.

6. git commit -m "Update index.html: Add project features list"
Saves the updated version of index.html into the repository history with an explanatory message.

7. git branch feature
Creates a new branch named 'feature' pointing to the current commit on the main branch.

8. git checkout feature
Switches the active working branch from 'main' to the 'feature' branch so new work can be done in isolation.

9. git branch
Lists all local branches in the repository, with an asterisk (*) marking the currently checked-out branch.

10. git add about.html
Stages the modifications made to about.html while working on the feature branch.

11. git commit -m "Add contact information section to about.html"
Commits the changes made on the feature branch into the repository history.

12. git checkout main
Switches the active branch back to 'main' before integrating changes from the feature branch.

13. git merge feature --no-ff -m "Merge branch 'feature' into main"
Merges the changes from the 'feature' branch into 'main', creating an explicit merge commit to preserve the branch history.

14. git log --graph --oneline --decorate --all
Displays the complete commit history in a compact, single-line format with an ASCII graph showing branching and merging relationships.

15. git add .gitignore
Stages the .gitignore file so Git tracks the rules for ignoring log files and temporary folders.

16. git commit -m "Add .gitignore to exclude .log files and temp directory"
Records the .gitignore file into the repository to prevent untracked artifacts from being staged in the future.

17. git reset HEAD~1
Undoes the most recent commit by moving the HEAD pointer back by one commit while leaving the file modifications in the working tree.

18. git remote add origin https://github.com/cidkagenou198/bits-git-assignment.git
Links the local repository to a remote repository hosted on GitHub under the alias 'origin'.

19. git branch -M main
Renames or confirms the primary branch name as 'main' before pushing to the remote repository.

20. git push -u origin main
Pushes all commits on the local 'main' branch to the remote repository on GitHub and sets up upstream tracking.
